# Markdown Basics

Reference cheat sheet for standard Markdown syntax, plus the Obsidian-specific extensions used in this vault.

## Standard Markdown

### Headings

```markdown
# Heading level 1
## Heading level 2
### Heading level 3
#### Heading level 4
##### Heading level 5
###### Heading level 6
```

Alternate style for H1/H2:

```markdown
Heading level 1
===============

Heading level 2
---------------
```

### Paragraphs and line breaks

Separate paragraphs with a blank line. To force a line break within a paragraph, end the line with two or more spaces before pressing return.

### Emphasis

```markdown
**bold text**
__bold text__

*italic text*
_italic text_

***bold and italic***
___bold and italic___
__*bold and italic*__
**_bold and italic_**
```

### Blockquotes

```markdown
> Dorothy followed her through many winding passages.

> First paragraph.
>
> Second paragraph.

> Outer quote
>> Nested quote
```

### Lists

Ordered:

```markdown
1. First item
2. Second item
3. Third item
```

Unordered (`-`, `*`, or `+` all work):

```markdown
- First item
- Second item
  - Nested item
```

### Code

Inline code: `` `nano` ``

Code block (indent every line by four spaces or one tab, or use fenced code blocks):

````markdown
```
code block
```
````

### Horizontal rules

```markdown
***
---
___
```

### Links

```markdown
[Duck Duck Go](https://duckduckgo.com)
[Duck Duck Go](https://duckduckgo.com "The best search engine for privacy")
<https://www.markdownguide.org>
```

Reference-style links:

```markdown
[hobbit-hole][1]

[1]: https://en.wikipedia.org/wiki/Hobbit#Lifestyle "Hobbit lifestyles"
```

### Images

```markdown
![Alt text](/assets/images/san-juan-mountains.jpg "Title")
```

Linked image:

```markdown
[![Alt text](/assets/images/shiprock.jpg "Title")](https://example.com)
```

### Escaping characters

Prefix with a backslash to show a character literally instead of using it as formatting:

```markdown
\* Without the backslash, this would be a bullet in an unordered list.
```

### Raw HTML

Inline HTML is passed through unchanged, e.g. `This <em>word</em> is italic.`

## Obsidian-specific syntax

### Wikilinks and block references

```markdown
[[Note Name]]
[[Note Name|Display Text]]
[[Note Name#Heading]]
[[Note Name#^block-id]]
[[#Heading in this note]]

This paragraph is addressable. ^block-id
```

Use wikilinks for notes inside the vault; use regular Markdown links for external URLs. A block ID goes on its own line, right after the block it refers to.

### Embeds

Prefix a wikilink with `!` to embed its content:

```markdown
![[Note Name]]
![[Note Name#Heading]]
![[image.png|300]]
![[document.pdf#page=3]]
```

### Callouts

```markdown
> [!note] Title is optional
> Callout content.

> [!warning] Custom title
> Important content.

> [!faq]- Collapsed by default
> Foldable content.

> [!faq]+ Expanded by default
> Visible but collapsible.
```

Built-in types (with aliases): `note`; `abstract` (`summary`, `tldr`); `info`; `todo`; `tip` (`hint`, `important`); `success` (`check`, `done`); `question` (`help`, `faq`); `warning` (`caution`, `attention`); `failure` (`fail`, `missing`); `danger` (`error`); `bug`; `example`; `quote` (`cite`).

### Properties (frontmatter)

```yaml
---
title: My Note
date: 2026-09-04
tags:
  - project
aliases:
  - Alternate Name
related: "[[Other Note]]"
---
```

Wikilinks used as property values must be quoted.

### Tags and comments

```markdown
#tag
#nested/tag

%%This is an inline comment, hidden in reading view%%
```
